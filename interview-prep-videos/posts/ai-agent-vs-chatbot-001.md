## Instagram caption

EP 02 · "An agent is just a chatbot with an API." That one line can end your interview.

A chatbot takes a message and gives one reply. An agent gets a goal and runs a loop: think, call a tool, observe the result, repeat until done. The real difference is control flow: in an agent, the LLM picks the next step, not fixed code.

The trap: agents are slower and costlier, so don't use them for simple questions. And the LLM never runs tools itself. It only returns a tool name + JSON, and your code executes it. That is where step limits, budgets, minimal permissions and human approval go.
